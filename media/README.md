# Media Assets

Organized storage for all project media assets.

## Folders

- **images/** — Screenshots, diagrams, UI mockups
- **documents/** — PDFs, reports, technical specifications
- **charts/** — Chart assets, data visualizations
- **videos/** — Demo videos, tutorials
- **models/** — Trained model artifacts, exports

## Usage

Use relative paths in documentation:
```markdown
![Screenshot](media/images/advisor-queue.png)
[Report](media/documents/Phase1_DataProfile.pdf)
```
